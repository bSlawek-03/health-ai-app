# Health AI App

## Project Description
Health AI App is a cloud-based web application for monitoring health activity and generating AI recommendations.

## Features
- Health dashboard
- Activity tracking
- AI recommendations
- User profile management
- Charts and analytics

## Technologies
### Frontend
- React
- Tailwind CSS
- Recharts

### Backend
- Node.js
- Express.js

### DevOps
- Docker
- Docker Compose
- GitHub

### AI
- OpenAI API
